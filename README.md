# CS2 LAN Practice

Скрипты PowerShell для запуска и остановки приватного LAN-сервера Counter-Strike 2 на Windows из уже установленной игры.

## Возможности

- Выделенный сервер: `sv_lan 1`, карта Dust II, casual, без ботов по умолчанию.
- Пароль генерируется при запуске либо задаётся параметром.
- Фоновый запуск; логи и состояние сохраняются в `.local/` и исключены из Git.
- Остановка проверяет PID, путь и время запуска, чтобы не завершить другой процесс.

Это только управление LAN-сервером. В проекте нет ESP, wallhack, чтения памяти игры, внедрения DLL, обхода античита или живой веб-карты. Сервер не запускается при скачивании репозитория.

## Требования

Windows, PowerShell 5.1 или новее, установленный Steam и актуальная CS2. Друзьям нужна совместимая версия CS2 и подключение к той же локальной сети.

## Запуск

Откройте PowerShell в папке проекта. Укажите свою папку игры:

```powershell
.\start-server.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive'
```

Необязательные параметры: `-Map de_mirage`, `-Port 27025`, `-Password YourOwnPassword123`. Разрешены буквы латиницы, цифры, дефис и подчёркивание; пароль от 8 до 64 символов. Не публикуйте свой пароль.

Скрипт выведет команду подключения с паролем. Включите консоль разработчика в настройках CS2 и выполните эту команду. На компьютере сервера используется `127.0.0.1`. Друзьям передайте IPv4 активного сетевого адаптера из `ipconfig` и тот же порт.

## Остановка

```powershell
.\stop-server.ps1
```

Остановка завершает процесс выделенного сервера; текущая тренировочная сессия заканчивается. Скрипт не останавливает произвольные процессы CS2.

## Подключение друзей и брандмауэр

Если подключение блокируется, администратор Windows может разрешить только UDP-порт сервера для локальной подсети. Скрипты не меняют брандмауэр автоматически. Не нужны проброс портов роутера и публикация сервера в интернете.

Пример для PowerShell от имени администратора, с вашим реальным путём:

```powershell
New-NetFirewallRule -DisplayName 'CS2 LAN Practice UDP 27025' -Direction Inbound -Action Allow -Protocol UDP -LocalPort 27025 -Program 'D:\SteamLibrary\steamapps\common\Counter-Strike Global Offensive\game\bin\win64\cs2.exe' -RemoteAddress LocalSubnet -Profile Any
```

Удалить созданное правило при необходимости:

```powershell
Remove-NetFirewallRule -DisplayName 'CS2 LAN Practice UDP 27025'
```

## Проверка и ограничения

В ходе подготовки исходная команда запуска загрузила `de_dust2` и ответила на локальный запрос A2S_INFO. Итоговые скрипты проверены синтаксически без повторного запуска игры. Подключение со второго компьютера не проверялось; автоматическое создание правила брандмауэра было отклонено Windows из-за отсутствия прав администратора.

Если сервер завершился, проверьте `.local/stdout.log` и `.local/stderr.log`. При ошибке определения каталога Steam убедитесь, что Steam установлен для текущего пользователя, и запускайте из обычного пользовательского PowerShell.

Бинарные файлы CS2 и Steam не включены. Официальный пример команды выделенного сервера опубликован Valve в [обновлении от 29 сентября 2023](https://store.steampowered.com/news/posts/?appids=730&enddate=1697825171&feed=steam_community_announcements).
